## Run the Demo Application

Open the demo application directory:

```bash
cd ostad-node-demo
```

Start the Node.js server:

```bash
npm start
```

Open the local application:

```text
http://localhost:3000
```

Expose the application using ngrok:

```bash
ngrok http 127.0.0.1:3000
```
